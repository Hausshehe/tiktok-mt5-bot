# Development Rules

1. Keep this repository completely separate from Nova.
2. Prefer GitHub-side work whenever the connector can perform it.
3. Use the user's phone only for actions that require a real MT5 terminal/device, such as compiling and Strategy Tester execution.
4. Keep V1 small and testable.
5. Every trading-risk control must be explicit and bounded.
6. Do not claim profitability from code correctness or backtests alone.
7. Do not add architecture that does not materially improve the bot's testability or safety.
8. Review code before asking the user to run it.
